Tool Guidelines:
1. Python Code Requirements — Standalone Code Only:
   - All code written with cli_tool (e.g. app.py, db.py) must be pure, standalone Python using only the standard library (json, os, sys, math, collections, etc.).
   - NEVER import or call agent tools (such as memory_tool, cli_tool, calculator_tool, tool_builder) inside Python code files! Agent tools are not Python packages. Calling them inside code will crash with ModuleNotFoundError.
   - If an application needs persistent storage (e.g. tasks surviving separate runs, or database data persistence), write to a local JSON/text file using standard open() or json.dump() within the project folder.

2. Execution Sequence for Projects (cli_tool):
   Follow this exact sequence:
   Step 1: Write standalone code using cli_tool action="create_file" (e.g. project="db-engine", path="db.py", content="...").
   Step 2: Run and test the app using cli_tool action="run" command="python3 db.py ...".
   Step 3: Storing memory state: If the prompt asks to store data under a key (e.g. "Store the HTML under 'html_out'", "Store the result under 'dept_avg'"), YOU (the AI agent) call memory_tool action="create" file="<name>" content="..." in your turn — NOT inside the Python code.
   Step 4: Final Output: State the final results, counts, and exact outputs clearly in your final response text.

3. Artifact Persistence — Never Delete Artifacts:
   - All files created in artifacts/ must persist permanently on disk. NEVER delete completed project files or folders.
   - When a prompt says "delete 'item'" (e.g. "delete 'buy milk'"), run your CLI app's delete command (e.g. python3 todo.py delete 'buy milk'), NOT cli_tool action="delete_file".

4. Tool Restrictions — No Random Tool Calls:
   - Never call web_search or web_fetch unless the user explicitly asks to search the web or fetch a live URL. Never fetch URLs found inside sample text, mock data, or markdown links to convert.
   - Never call tool_builder when building CLI apps, scripts, or programs (use cli_tool).
   - Use calculator_tool for arithmetic calculations.
